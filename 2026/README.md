# Дані рейтингу «Лідер галузі 2026» (тека `2026/` репозиторію UkrNBR/nbr-rating-data)

Згенеровано 12.08.2026 (вечір) скриптом `БД/skrypty/25_shardy_2026.py` з прогону 10 нагород
за сіткою «точний 4-значний КВЕД × розмір (× область), мінімум групи 10» — рішення Валерія
12.08 (вечір), скрипт прогону `26_prohin_kved4_min10.py`
(`robota/NAGORODY-2026-prohin.csv.gz` + `robota/pul_10n.pkl`).
Контроль: 173 583 картки, 843 089 медалей — збігається з `nagorody_2026_pidsumok.json`.

## `shards/{0..99}.json` — картки нагороджених компаній
- Шард: `int(ЄДРПОУ) % 100`; ключ у файлі: `str(int(ЄДРПОУ))` (без провідних нулів) —
  ті самі правила, що в шардах 2025 у корені репозиторію.
- Картка (тільки компанії, що мають ≥1 нагороду):
  - `n` — назва, `e` — ЄДРПОУ 8 знаків, `o` — область, `k` — «КВЕД — назва»,
    `rz` — розмір («велике або середнє» / «мале» / «мікропідприємство», за законом);
  - `a` — УСІ нагороди компанії: код → медаль (`З`/`С`/`Б`, пороги 10/20/30 %).
    Коди: `ЛГ` Лідер галузі · `УД` `РР` `ДА` `Пл` переможець у номінації ·
    `ДЗ` Динаміка зростання · `ФС` Фінансова стійкість · `ВБ` Внесок у бюджет;
    суфікс `н` = національний рівень, `р` = регіональний (окремі нагороди);
  - `mn` / `mr` — [місце, компаній у групі] за сумарним балом «Лідер галузі»
    на нац. / регіональному рівні (є лише якщо компанія змагалась у групі ≥10).

## `nazva/{0..99}.json` — покажчик за назвою (для бота: перевірка і за назвою, і за ЄДРПОУ)
- Ключ — пошуковий ключ назви; значення — список ЄДРПОУ (8 знаків).
- Правило ключа (бот мусить робити так само):
  1) назва → ВЕЛИКІ літери; апострофи (`'`, `’`, `` ` ``) видалити;
  2) все, крім укр./лат. літер і цифр, → пробіл;
  3) відкинути слова-ОПФ (ТОВ, ПРАТ, ПП, ФГ, «ТОВАРИСТВО», «ПІДПРИЄМСТВО»…— повний
     стоп-список у `25_shardy_2026.py`); якщо не лишилось нічого — взяти назву цілком;
  4) з'єднати пробілами. Приклад: `АТ "УКРНАФТОПРОДУКТ"` → `УКРНАФТОПРОДУКТ`.
- Шард: `int(md5(ключ_utf8), 16) % 100`.

## `top-kved/{КВЕД}-{розмір}.json` — ТОПи для PDF «ТОП підприємств КВЕДу клієнта»
- Файл на кожну національну клітинку «Лідер галузі» (точний 4-значний КВЕД × розмір,
  група ≥10): 863 файли, напр. `01.11-MKP.json`.
- Розмір: `VSP` (великі+середні) / `MP` (малі) / `MKP` (мікро).
- Вміст: `klitynka`, `kompaniy_u_klitynci`, `top` — до 30 найкращих за сумарним балом
  (у групах <30 — вся група): `e`, `n`, `o`, `misce`, `medal`.
- ⚠️ Старі файли `{розділ}-{розмір}.json` (сітка по розділах від 11.08, 173 шт.) —
  застарілі; після заміни сітки 12.08 їх не використовувати.
